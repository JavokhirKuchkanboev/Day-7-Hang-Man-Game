
# 🎯 Day 7 – Hangman Game

Part of my **100 Days of Code (Python)** journey.

---

## 📌 **Project Overview**

Hangman is a classic word-guessing game where the player tries to uncover a hidden word one letter at a time.
Every wrong guess reduces the number of lives. If lives reach zero — the game ends.

This project helped me practice:

* Lists
* Loops
* Conditional logic
* Functions
* ASCII art
* Importing modules
* Game state tracking

---

## 🧠 **Key Learnings**

✔ How to structure a multi-file Python project
✔ How to manage game logic using loops
✔ How to track user guesses and update the display
✔ How to use ASCII art for dynamic visuals
✔ Error handling for repeated guesses

---

## 📂 **Project Files**

```
HangMan.py       # Main game logic
art.py           # ASCII art (logo + hangman stages)
words.py         # Word list used in the game
```

---

## ▶️ **How to Run**

```bash
python HangMan.py
```

---

## 📝 **Features**

* Random word selection
* Lives system using hangman stages
* Repeated guess detection
* Step-by-step reveal of hidden letters
* Clean console-based interface
